## Context

High-traffic media platforms serving **20M+ MAU** have to stay fast for every reader. Core Web Vitals, and LCP and INP in particular, were the measures to move.

## My role

As SDE-3, I drove the **Core Web Vitals optimization** across these platforms.

## How we did it

- **Strategic SSR**, to improve what readers see first.
- **Asset optimization**, backed by asset pipeline governance.

## Outcome

- **30% gain** in LCP.
- **35% gain** in INP.
